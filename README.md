# نور الإسلام — تطبيق إسلامي شامل

تطبيق Flutter باللغة العربية مبني على **القرآن الكريم والسنة النبوية الصحيحة وفهم السلف الصالح** (أهل السنة والجماعة). واجهة كاملة من اليمين إلى اليسار (RTL)، مع وضع ليلي/نهاري، وخطوط عربية أصيلة، وإشعارات تذكير بالأذكار.

---

## المحتوى والأقسام

- **الأذكار**: الصباح، المساء، النوم، السفر، أذكار متفرقة — مع تخريج الأحاديث.
- **الصلاة**: الطهارة، الأحكام، الكيفية (أركان/واجبات/سنن).
- **التوحيد**: أنواع التوحيد ونواقضه.
- **أركان الإسلام**: شرح موجز مدعوم بالأدلة.
- **تفسير القرآن**: تفسير السعدي (الفاتحة والمعوذات كبداية).
- **المكتبة الإسلامية**: الأصول الثلاثة، القواعد الأربع، كشف الشبهات، كتاب التوحيد، نواقض الإسلام، الأربعون النووية.
- **حفظ القرآن**: خطة ونصائح للحفظ والمراجعة.
- **المفضلة، الملاحظات، البحث، الإعدادات، قناة تيليجرام.**

---

## المتطلبات

- Flutter SDK 3.x فأحدث (Dart `>=3.0.0`).
- Android SDK (للبناء كملف APK) — `minSdk 21`, `targetSdk 34`.
- JDK 17 (الموصى به مع Gradle 8.4).

---

## خطوات البناء (APK)

1. **فك ضغط الأرشيف** والدخول إلى مجلد المشروع:
   ```bash
   cd islamic_app
   ```

2. **ضبط مسار Flutter SDK** — أنشئ ملف `android/local.properties` بالمحتوى التالي (عدّل المسار حسب جهازك):
   ```properties
   flutter.sdk=C:\\src\\flutter
   sdk.dir=C:\\Users\\<YOU>\\AppData\\Local\\Android\\sdk
   ```
   > ملاحظة: هذا الملف غير مضمّن في الأرشيف عمدًا لأنه خاص بكل جهاز.

3. **جلب الحزم**:
   ```bash
   flutter pub get
   ```

4. **بناء APK للإصدار**:
   ```bash
   flutter build apk --release
   ```
   الملف الناتج:
   ```
   build/app/outputs/flutter-apk/app-release.apk
   ```

5. **التشغيل على جهاز/محاكي مباشرة** (اختياري):
   ```bash
   flutter run
   ```

## البنية التقنية

| العنصر | التقنية |
|--------|---------|
| إدارة الحالة | `provider` |
| التخزين البسيط | `shared_preferences` |
| الملاحظات | `sqflite` |
| الإشعارات | `flutter_local_notifications` + `timezone` |
| الروابط والمشاركة | `url_launcher` + `share_plus` |
| الخطوط | Noto Naskh Arabic (الواجهة) + Amiri (القرآن) |

المحتوى مخزّن كملفات **JSON** ضمن `assets/`، مما يسهّل التوسّع مستقبلًا بإضافة كتب وتفاسير وأذكار جديدة دون تعديل الكود.

---

## التوسعة المستقبلية

لإضافة كتاب جديد: أضف ملف JSON في `assets/books/` وسجّله في `assets/books/index.json`.
لإضافة سورة للتفسير: أضفها في `assets/tafsir/tafsir.json`.
لإضافة فئة أذكار: أضف ملفًا في `assets/adhkar/` واربطه في شاشة فئات الأذكار.

---

## المصادر

جميع المصادر موثّقة في `assets/references.md` (كتب العقيدة والتفسير والحديث والفقه والأذكار مع تخريج الأحاديث من البخاري ومسلم وأبي داود وغيرهم).
